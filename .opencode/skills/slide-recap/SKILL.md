---
name: slide-recap
description: Consistent format for turning a slide deck into a recap with a Mermaid concept map
---
When producing a recap:
1. Header: deck name and date
2. "Key Concepts" list (max 10)
3. "Topic Summaries" (2-3 sentences each)
4. "Concept Map" as a Mermaid flowchart TD with max 12 nodes
5. End with "Open Questions" if any slides were unclear
Save the result to output/<deck-name>-recap.md
